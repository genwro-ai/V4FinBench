# Polish Companies Bankruptcy

Source: UCI Machine Learning Repository, dataset 365  
DOI: https://doi.org/10.24432/C5F600  
License: CC BY 4.0

The five ARFF files contain observations one to five years before the reported
bankruptcy outcome. The filenames use the original dataset convention:
`5year.arff` is the one-year-ahead task and `1year.arff` is the
five-year-ahead task.

Variables used in the validation:

- `Attr10`: equity / total assets
- `Attr48`: EBITDA / total assets
- `Attr4`: current assets / short-term liabilities
- `class`: reported bankruptcy outcome
