# Data Provenance

V4FinBench was constructed from company-level financial statement data extracted from EMIS, together with company metadata such as country, industry classification, legal form, operational status, and number of employees.

The raw EMIS files are not redistributed. As a result, the public reproduction path starts from the released Kaggle parquet files rather than from the original EMIS extraction.

The repository may document the extraction and cleaning decisions for transparency, but raw Excel ingestion is not required to reproduce the public benchmark evaluations.
